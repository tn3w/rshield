# Security Policy

## Reporting a vulnerability

If you discover a security vulnerability in rshield, please report it responsibly.

**Do not open a public issue.**

Instead, use [GitHub's private vulnerability reporting](https://github.com/tn3w/rshield/security) with:

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We aim to acknowledge reports within 48 hours and provide a fix or mitigation plan within 7 days.

## Supported versions

| Version | Supported |
| ------- | --------- |
| latest  | yes       |

## Scope

Security issues in rshield's middleware, IP validation, proof-of-work and CAPTCHA generation, and cookie handling are in scope. Issues in third-party dependencies should be reported to their maintainers.
